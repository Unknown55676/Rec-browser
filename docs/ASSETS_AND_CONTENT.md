# Assets and user-created content

## Allowed content sources

Use:
- Models, textures, sounds, and animations created for this project.
- Assets whose licenses explicitly permit this use.
- User-provided content where the user has the rights and permission to use it.
- Public-domain content, while retaining provenance notes where possible.

For each third-party asset, record its source, creator, license, and any attribution requirements.

## Do not bundle

Do not add proprietary Rec Room client files, extracted game assets, paid marketplace assets without a suitable license, account data, or private server credentials. Do not bypass DRM, anti-cheat, access controls, or account protections to obtain content.

## Suggested asset layout

```text
assets/
  avatars/
  environments/
  props/
  audio/
  ui/
  LICENSES.md
```

Keep large binary assets out of Git unless their license allows redistribution and repository storage is appropriate. Use optimized glTF/GLB for 3D models where possible.
